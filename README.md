## ⚙️ Getting Started

### Prerequisites
- Python 3.x installed → [Download here](https://www.python.org/downloads/)

### Clone the Repository

```bash
git clone https://github.com/Abhinikesh/Py_Projects.git
cd Py_Projects
```

### Run Any Project

```bash
# Example
cd Quiz_game-main
python main.py
```

> Each project folder contains its own Python file(s). Navigate into the folder and run the main script.
